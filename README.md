# uwufufu-api

> Unofficial, reverse-engineered TypeScript SDK and API documentation for [uwufufu.com](https://uwufufu.com).

⚠️ **Disclaimer** — This project is **not affiliated with, endorsed by, or supported by uwufufu**. It is built by observing the website's public network traffic for interoperability and automation purposes. Endpoints are undocumented and may change without notice. Use responsibly and respect uwufufu's terms of service and rate limits.
